# AgentForge

> Production-oriented platform for building, evaluating, and monitoring AI agents.

## 🚀 Overview

AgentForge is an open-source AI agent evaluation platform designed to help developers build reliable, measurable, and production-oriented AI agents.

The platform will provide:

- AI agent orchestration
- Tool calling
- Retrieval-Augmented Generation (RAG)
- Automated task evaluation
- Agent failure analysis
- Performance metrics
- Token and cost tracking
- API access
- Evaluation dashboards
